# MaatriCare AI - Frontend

Static HTML, CSS, and JavaScript frontend for MaatriCare AI.

## Structure

- `index.html` — Landing page
- `pages/` — All app pages (login, dashboard, reminders, diet, wellness, shopping, education, hospital-finder)
- `css/styles.css` — All styles
- `js/layout.js` — Shared sidebar layout logic
- `public/` — Static assets (favicon, icons)

## Running

The backend server (in `../backend/`) serves these static files. Start the backend and open `http://localhost:5000` in your browser.

## Icons

Uses [Lucide Icons](https://lucide.dev/) via CDN.
